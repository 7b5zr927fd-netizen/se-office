# 🕶️ SE Офіс

Одна програма, де ви спілкуєтесь із різними ШІ (Claude, ChatGPT, DeepSeek, Kimi, Gemini, Llama, OpenRouter), підключаєте Notion і даєте ШІ читати та редагувати ваші таблиці. ШІ можуть шукати в інтернеті, а коли завершать роботу, програма сповістить вас.

## Для користувача

**Через інсталятор** (якщо вам дали файл `.exe` / `.dmg` / `.AppImage`): встановіть і запустіть, як звичайну програму.

**Через архів:** встановіть один раз Node.js (кнопка LTS, nodejs.org), розпакуйте архів і двічі клацніть `start.bat` (Windows), `start.command` (Mac) або `start.sh` (Linux). Відкриється http://localhost:3000. Не закривайте чорне вікно, поки працюєте.

### Віртуальний офіс
Вкладка «🏢 Офіс» — це затишний вечірній піксельний простір. Агенти неквапливо прогулюються, а коли ви надсилаєте завдання — зупиняються, відгукуються, вислуховують і йдуть до свого ноутбука. Під час роботи над столом видно актуальний статус; після завершення агент повертається до офісу, а відповідь з'являється під сценою. Клікніть на працівника, щоб обрати його; подвійний клік відкриває чат.

### Перший вхід
Програма сама відкриє «Підключення». Підключіть хоча б одного ШІ:
- **Найпростіше:** «🔐 Увійти через OpenRouter» — вхід у свій акаунт одним кліком, далі доступні моделі різних компаній.
- **Безкоштовно:** Gemini (aistudio.google.com/apikey) або Groq (console.groq.com/keys).
- Інші: Claude, ChatGPT, DeepSeek, Kimi — вставте API-ключ (посилання «Де взяти ключ» біля кожного).

Підписки (ChatGPT Plus, Claude Pro тощо) не дають доступу до сторонніх програм: потрібен API-ключ, який оплачується окремо за використання.

### Notion
1. notion.so/profile/integrations → New integration → скопіюйте токен у «Підключення».
2. На своїй сторінці Notion: `···` → Connections → додайте цю інтеграцію.
3. Тепер просіть ШІ в чаті: «покажи таблицю…», «зміни статус рядка…». Кожну зміну потрібно підтвердити, видалення заблоковане.

### Інтернет і сповіщення
- Галочка «🌐 Доступ ШІ до інтернету» дає пошук і читання сайтів. Локальна мережа заблокована.
- Галочка «🔔 Сповіщення» вмикає звук і системні сповіщення, поки програма запущена.
- Telegram (необов'язково): бот від @BotFather + ваш Chat ID від @userinfobot, напишіть боту /start. Тоді повідомлення приходять на телефон.

Історія чатів зберігається в браузері на вашому комп'ютері. Ключі лежать у `data/settings.json` — нікому його не передавайте.

## Для власника: як роздавати користувачам один файл

1. Створіть репозиторій на github.com і завантажте в нього всю цю папку (разом із `.github`).
2. Для випуску створіть новий тег версії, наприклад: `git tag v1.3.3` і `git push origin v1.3.3`.
3. GitHub сам збере інсталятори для Windows, Mac і Linux (вкладка Actions, ~10 хвилин). Готові файли з'являться в **Releases**.
4. Дайте користувачам посилання на **Releases**: вони завантажують новий інсталятор і встановлюють його.

Локальна збірка на своєму комп'ютері: `npm install`, потім `npm run dist` (результат у папці `dist`). Перевірка у вікні: `npm run desktop`.

### Як оновити код у своєму GitHub

1. Відкрийте локальну копію репозиторію, яку ви вже клонували з GitHub. Скопіюйте з архіву оновлені `public/index.html`, `public/office.js`, `public/app.js`, `README.md` і `package.json` у локальний репозиторій. Не видаляйте приховану папку `.git` — саме вона зберігає зв’язок із репозиторієм.
2. У терміналі, відкритому в папці проєкту, виконайте:

```bash
git pull --rebase
git add public/index.html public/office.js public/app.js README.md package.json
git commit -m "Оновити затишний дизайн офісу"
git push
```

3. Це оновить вихідний код у GitHub. Щоб автоматично зібрати нові інсталятори, після успішного `push` створіть тег нової версії, наприклад `git tag v1.3.3`, і відправте його: `git push origin v1.3.3`. Збірка запускається в **Actions**, а готові файли з’являться в **Releases**. Для простого оновлення вихідного коду тег не потрібен.


Примітки: інсталятори без цифрового підпису — Windows і Mac покажуть попередження «невідомий видавець», це нормально для початку. Підпис купується окремо.

## Як додати ще один ШІ
1. `server.js` → `PROVIDERS`: додайте рядок за зразком DeepSeek (адреса `base`, модель, назва змінної ключа). Підходить будь-який сервіс з OpenAI-сумісним API.
2. `public/app.js` → `PV`: той самий `id` і посилання на ключі.
3. `public/config.js` → `team`: ім'я, роль, колір.

## Безпека
- Сервер слухає лише 127.0.0.1 і відхиляє запити з інших сайтів.
- Інтернет-інструменти не відкривають адреси локальної мережі.
- Текст із сайтів ШІ вважають даними, а не інструкціями, але в інтернеті можливі шахрайські сторінки: не вмикайте інтернет, якщо працюєте з чутливими даними.
